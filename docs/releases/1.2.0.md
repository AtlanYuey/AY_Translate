AY Translate 1.2.0，漫画气泡与手写排版优化。支持 iPhone 和 iPad，最低系统版本为 iOS / iPadOS 26.5。

- **气泡识别**：本机找出对话气泡，气泡里没被识别到的短台词（「わっ」「ぱぱー！」「えと…」这类）会单独再读一次；小写っ保持小写，长音ー、竖排省略号转回正确方向，「!」保持直立。
- **一个气泡一句话**：同一气泡里的多列合成一句再翻译，重复识别的列自动去掉，不会再出现两份译文叠在一起。
- **注音不送去翻译**：汉字旁边明显小一号的假名判定为注音，只保留在全文里。
- **译文按气泡排版**：译文在整个气泡里居中排版；中文比日文短时会用空出来的位置把字放大（最多 1.3 倍），全页对话字号保持一致，不再忽大忽小。
- **绝不叠字**：两块译文要重叠时先各自收回原位置，仍重叠就保留其中一处原文（点按或全文可看译文）。
- **手写彩色台词**：按墨迹颜色区分说话人，不同颜色的相邻台词不会被并成一句；译文沿用原文颜色，并自动加深到清晰可读。
- 只有省略号、符号的区域不再覆盖。

手写体、画面上的拟声词仍受苹果本机识别能力所限；这类页面建议识别引擎选用 Gemini 等多模态模型，AI 识别结果同样会按气泡和颜色整理。
