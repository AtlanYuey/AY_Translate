# 1.0.0 首发验证记录

发布代码与安装包对应提交 `82244f6d9ee27ee86a87b5804378ef4a7b2e3ef5`，标签 `v1.0.0`。

[Apple 构建和测试运行](https://github.com/AtlanYuey/AY-Translate/actions/runs/42523355064)：构建、原生识别、iPhone 和 iPad 作业全部通过。自动发布作业因附件名称仍使用旧前缀而失败；主分支已修正名称，首发上传的是同一运行中生成并核验的 IPA，未重写版本标签。

- Linux 核心测试 101 项通过；macOS 26 核心/实际 Vision 测试 112 项通过。
- 手写风格、歪斜、小字、带注音的中立日文样图，正文 24/24 逐字匹配。8 像素注音仍有漏读误读，未宣称完全识别。
- iPhone Air 模拟器 74 项流程测试、4 项界面测试通过，iPad 横竖屏检查通过。
- 同一扩展进程连续完成 6 次分享，0 次内存警告；观测峰值 129,653,120–136,632,832 字节。模拟器不代表任意真机图片都不会遇到内存压力。
- 已保留系统分享宿主高度的已知预期失败：834 与期望 884.64 点，实际宿主可能以卡片显示。
- 主应用/分享扩展版本均为 1.0.0（1），主 ID 为 `com.atlanyuey.translate`，扩展为 `.ShareExtension`，支持 iPhone/iPad，最低系统 26.5。
- 已核对 arm64、未签名状态、新图标与品牌资源、两份 bundle 中的 Apache/NOTICE/MIT 许可。测试用字体不包含在安装包中。
- 随包快捷指令由 Apple 环境核验证书链和归档签名，并提取检查动作与源模板一致，目标为新应用 ID。未进行真机 Shortcuts 端到端测试。
- iCloud 权限模板已配置；没有访问 Apple Developer 账号或注册标识，也没有验证个人签名下的跨设备同步。
