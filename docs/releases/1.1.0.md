AY Translate 1.1.0，识别与翻译优化版。支持 iPhone 和 iPad，最低系统版本为 iOS / iPadOS 26.5。

- **AI 翻译更快**：按字数把整屏文字分成几批并行请求，每批都带完整的整屏上下文；长截图、漫画多气泡页面的等待时间明显缩短。
- **不漏、不多**：某个区域漏译或输出成错误语言时，只对这些区域补译一次，已译好的不重复请求；仍失败时保留已完成的译文，只有失败区域显示原文，不再整页报错。
- **更贴合截图文字的翻译要求**：说明 OCR 的换行只是排版、允许修正明显的形近误识、不加注释和罗马音、目标语言原文保持不变、名字和术语前后一致。
- **临时故障自动恢复**：服务限流（429）或临时错误（5xx）会按服务端建议等待后重试一次；模型在 JSON 前后多说的话不再导致失败。
- **AI 识别（Gemini 等）更完整**：Gemini 使用其原生 `box_2d` 坐标格式，定位更准；苹果识别漏掉、只有 AI 读到的文字（常见于手写）在本机像素确认有笔画后直接覆盖译文，框贴合实际笔迹。空白处的“幻觉文字”不会被画到图上。
- **主 App 小字识别更准**：主 App 改为与分享扩展相同的原像素分块识别，修复整图识别时 11～12px 小字的误读。
- **本机识别按实际内存调度**：分享扩展剩余内存充足（≥160 MB）时使用神经网络引擎并让两个识别器并行；内存紧张、刚收到内存警告或预算未知时自动退回原来的 CPU 串行方式。
- **其他提速**：识别过程中的诊断记录不再阻塞识别；有 App Group 时不再重复写钥匙串；“准备图片”阶段的背景修复约快 3.7 倍（输出逐像素相同）；处理中的边缘光晕绘制量减少约一半。

建议：使用 Gemini 等“思考型”模型做翻译时，在“设置 → AI 服务 → 请求参数”选择“推理 · 低”，可显著缩短等待，翻译质量基本不受影响。

下载 `AY-Translate-1.1.0-unsigned.ipa`，使用 Feather 等工具签名安装。主程序与分享扩展需要分别签名的原因见[优化说明](https://github.com/AtlanYuey/AY_Translate/blob/main/docs/AY-Translate-1.1.0.md)。
