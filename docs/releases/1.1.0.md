AY Translate 1.1.0。支持 iPhone 和 iPad，最低系统版本为 iOS / iPadOS 26.5。

### 识别更全、更准

- **漫画气泡**：自动找出对话气泡（包括被页边切掉的、锯齿形喊叫框、虚线框），一个气泡算一句话，整句翻译、在气泡里排版。两个画在一起的气泡沿交汇处分开，各自翻译。
- **该翻的不漏**：苹果识别漏掉的短句（わっ、えと…）在气泡里补读；竖排漏字补读；手写彩色台词按颜色区分说话人。
- **不该翻的不翻**：注音假名不混进正文；纯数字、时间、价格，被误读成其他文字的画面和拟声字，漫画页气泡外的水印、签名、版权行都保持原样，只在“全文阅读”里可查。
- **译文核对**：译成中文时，仍是日文的“译文”不会被接受，会重试并交给下一个服务；漏译、语言不对的区域只补译这些区域，已译好的不重复请求。

### 画面更干净

- 原文按整块擦除（连同描边和毛边），气泡轮廓和画面不动，不再留下灰色脏块。
- 译文只在原文位置周围、气泡形状以内排版；放不下时缩小，不出框。竖排分栏均匀，标点不放在列首，一列的旁白仍是一列。

### AI 服务

- **按顺序使用、出错接替**：识别和翻译各有一个使用顺序。第一个出错或达到花销上限时，下一个接手，最后由本机引擎兜底；发生切换时会提示。
- **只在需要时用 AI**：开启“AI 辅助识别”后先用本机识别，只有读得不可靠时（手写、艺术字、气泡里还有没读出的字）才交给 AI，可以设为先询问。
- **更快**：Gemini 等新模型默认使用轻量推理（此前会长时间“思考”直至超时）；AI 识别只回报需要更正的部分，同一页约 5 秒。翻译分批并行；AI 识别进行时，先翻译本机已读出的文字。
- **用量与花销**：每个服务记录本月和累计的输入/输出 token 与花费，可设每月花销上限。公布价格的服务商（如 OpenRouter）自动取价，其余手动填写；国内服务商可选人民币或美元。
- **更稳**：模型回复少括号、多说一句话、编号重复都能照常使用；限流和临时错误会自动重试一次。
- **许可时机**：是否允许把截图或文字发给某个服务，在选择这个服务时确认，翻译过程中不再弹窗。

### 使用体验

- 连按两次背板不会翻译两次，第二次直接接手第一次的进度；分享扩展启动更快。
- 结果页长按菜单直接列出耗时和各项 token 用量；复制合并为一项；新增“打开 AY Translate”。是否使用 AI 的询问显示在屏幕下方，不挡灵动岛。
- iCloud 同步可选择同时保存 API 密钥。
- 去掉“速度优先 / 质量优先”（两者差别很小，已合并为一套）；处理诊断移到“关于”。
- 主程序与分享扩展通过 App Group 共用设置；本机识别按扩展的实际剩余内存调度。

下载 `AY-Translate-1.1.0-unsigned.ipa`，需用自己的证书为主程序和分享扩展分别签名后安装，见 [签名与 iCloud 配置](https://github.com/AtlanYuey/AY_Translate/blob/main/docs/Signing-and-iCloud.md)。
