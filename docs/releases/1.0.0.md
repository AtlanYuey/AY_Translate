AY Translate 首个正式版本，面向 iPhone 和 iPad。最低系统版本为 iOS / iPadOS 26.5。

- 本机截图识别与苹果翻译，支持日文竖排、交叉查漏与原位置译文覆盖。
- 多 AI 服务、独立识别/翻译模型、模型列表、参数配置和测试。
- 原图对照、全文阅读、字体与描边、原生缩放、可选翻译历史。
- 蓝色截屏快捷指令，适配新应用 ID。
- 可选 iCloud 自动设置同步；新增“关于 → 开源许可”。

应用 ID：`com.atlanyuey.translate`。这是新的应用身份，旧测试版的设置不会自动迁入。可先在旧版配置同步页面复制配置，再在新版导入，并重新导入快捷指令。

下载 `AY-Translate-1.0.0-unsigned.ipa` 后，用 Feather 或其他工具签名安装。iCloud 需要签名描述文件支持匹配 App ID 的 KVS 权限，仅修改 ID 无法开通。密钥、图片和历史不参与同步。

已知限制：极小注音、模糊或复杂手写文字仍可能漏读；强化查漏增加本机处理开销。系统分享宿主可能以卡片展示；快捷指令实际触发及个人签名下的跨设备 iCloud 仍需真机验证。安装包经过自动构建和回归测试，详情见对应 Actions 运行。

基于 Bahaa 及贡献者的 Translate Screen 修改，以 Apache 2.0 发布，原项目署名和第三方图标许可随源码与应用保留。
