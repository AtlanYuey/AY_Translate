AY Translate 1.0.0，首次发布。支持 iPhone 和 iPad，最低系统版本为 iOS / iPadOS 26.5。

- 截图文字识别、日文竖排与原位置译文覆盖。
- 苹果本机引擎与多个 AI 服务，识别和翻译模型可独立选择。
- 模型列表、请求参数配置、文字翻译和图片识别测试。
- 原图对照、全文阅读、字号与显示样式、原生缩放。
- 蓝色截图快捷指令，可绑定操作按钮或轻点背面。
- 可选翻译历史和 iCloud 自动设置同步。

下载 `AY-Translate-1.0.0-unsigned.ipa`，使用 Feather 等工具签名安装。功能和设置入口见 [README](https://github.com/AtlanYuey/AY-Translate#readme)。

有自己的 Apple 开发者账号、希望使用 iCloud 同步，可参考[配置方法](https://github.com/AtlanYuey/AY-Translate/blob/main/docs/Signing-and-iCloud.md)。

基于 Bahaa 及贡献者的 Translate Screen 修改，以 Apache 2.0 发布，署名和相关许可随源码与应用保留。
