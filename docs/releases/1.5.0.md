AY Translate 1.5.0，按需调用 AI、可同步 API 密钥、设置整理。支持 iPhone 和 iPad，最低系统版本为 iOS / iPadOS 26.5。

- **需要时才用 AI 识别**：识别引擎选 Apple Vision 时，可以让 App 自己判断这张图本机是否读得可靠。判断只用本机信息，不上传任何内容：什么都没读出来、相当一部分文字把握很低（手写、艺术字）、画面被读成别的文字、气泡里读了一部分还剩字没读出。新增两个开关（识别引擎 → AI 辅助识别），默认都关闭：
  - “需要时自动使用 AI”：判断为不可靠时自动交给 AI 识别。
  - “需要 AI 时先询问”：只在上一项关闭时显示；打开后在图片上方询问是否使用 AI，本次选择对这张图一直有效。
  - 两项都关：始终只用本机识别。
- **同一张图的 AI 识别只付一次费**：之后换目标语言或换翻译引擎，直接复用已有的识别结果。
- **iCloud 可同时保存 API 密钥**：配置同步 → 打开 iCloud 同步后出现“同时保存 API 密钥”。开启后密钥和已给出的云端许可随 iCloud 到其他设备；新设备开启时先取回已有密钥再上传自己的，不会把别的设备的密钥清空。关闭会从 iCloud 删除。
- **云端许可在选择服务时询问**：在识别/翻译引擎里选中一个 AI 服务（或打开 AI 辅助、修改了正在使用的服务的地址或模型）时就确认是否允许把数据发给它，翻译过程中不再弹出。只有没经过这一步的情况（例如用“复制配置”导入）才会在第一次使用时询问一次。
- **设置整理**：去掉“速度优先/质量优先”（两者实际差别很小，现在统一为一套）；“处理诊断”移到“关于 → 开源许可”下面，列表改为每次处理一行。

下载 `AY-Translate-1.5.0-unsigned.ipa`，使用 Feather 等工具签名安装。
