AY Translate 1.7.0，连体气泡分开翻译、防止重复触发、用量分项显示。支持 iPhone 和 iPad，最低系统版本为 iOS / iPadOS 26.5。

- **连体气泡分开翻译**：两个画在一起、轮廓连成一片的气泡，现在会沿着两边轮廓交汇处的缺口切开，各自作为一句话翻译、在各自的气泡里排版，不再把两句拼成一段塞进一个框。只有两侧都有文字时才会切开；普通气泡（带尾巴、被人物遮住一角、云朵形）不受影响。
- **漏翻修正**：译成中文时，如果模型返回的仍是日文（判断依据是还剩相当比例的平假名，汉字本身不能区分中日文），不再当作译文接受：先让模型重译一次，仍是日文就交给顺序里的下一个服务，最后由本机翻译。
- **连按两次不会翻译两次**：第一次还在处理时（12 秒内）再次触发，第二次会直接接手第一次的进度，不重新识别、不重复计费；第二张截图只拍到了第一次的加载画面，不会使用。
- **启动更快**：分享扩展第一次启动时不再重复读取一遍共享设置。使用带 App Group 的描述文件签名后，主程序和分享扩展直接共用同一份设置，不再经过钥匙串中转。
- **用量分项显示**：结果页长按菜单里，耗时、AI 识别、AI 翻译各成一组；每组标题是服务名和金额，下面分行列出输入 token、输出 token。服务编辑页的“本月 / 累计”也分行显示。
